# Controle de Avarias V28.8 — Demonstração independente

Projeto de interface baseado nos arquivos da V28.8 original, sem identidade visual, imagens, documentos, dados ou conexão com qualquer empresa.

## GitHub Pages
Envie **o conteúdo desta pasta** à raiz do repositório, habilite Settings → Pages → Deploy from a branch → main / root.

Acesso: `demo` / `demo123` (exclusivamente demonstrativo; **não representa autenticação segura**).

## Aviso de funcionamento
Esta versão preserva os arquivos HTML/CSS/JS e a navegação do projeto original, mas substitui as chamadas de API por um emulador local, que utiliza `localStorage`. A integração com PostgreSQL e os serviços Node/Express operacionais foram removidos. Nem todos os módulos funcionam integralmente: relatórios avançados, documentos, importações e funções que dependem do servidor retornam indisponível. Não use esta versão para produção ou para armazenar informações reais. Diferentes navegadores não compartilham dados.

## Privacidade
Arquivos de backup, banco de dados, fotos e logos reais, documentos, planilhas, logs, dependências e scripts de conexão operacional foram excluídos deliberadamente. O código de front-end foi mantido, incluindo suas limitações anteriores.
