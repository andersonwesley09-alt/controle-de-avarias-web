# Controle de Avarias V25.1.21 — versão sem vínculo

Versão estática para GitHub Pages. Não usa Node.js, PostgreSQL ou o servidor da empresa.

## Como publicar
1. Coloque o conteúdo desta pasta no repositório do GitHub Pages.
2. Defina `index.html` como página inicial.
3. Publique normalmente pelo GitHub Pages.

## Importante
- Os dados desta versão ficam no navegador de cada pessoa (`localStorage`/`IndexedDB`).
- Ela **não sincroniza** com o sistema da empresa nem entre computadores.
- Arquivos do card Documentos ficam armazenados no navegador que os enviou.
- Esta versão é independente e serve para demonstração/uso local no navegador.
