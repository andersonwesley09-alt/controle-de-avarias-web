CONTROLE DE AVARIAS — V25.1.16

Atualização: edição de usuários.

- Novo botão "Editar" na tabela de usuários.
- Permite alterar nome e usuário de acesso.
- Senha continua sendo alterada por "Redefinir senha".
- Alterações usam a API central e são refletidas em tempo real nos demais PCs.
- Alteração de usuário não modifica perfil, situação ou registros do sistema.
- Em caso de nome de usuário duplicado, a operação é recusada sem alterar o cadastro.
