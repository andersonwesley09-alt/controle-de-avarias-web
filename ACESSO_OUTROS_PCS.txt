CONTROLE DE AVARIAS - V20.0
===========================

PC PRINCIPAL:
1. Execute LIBERAR_ACESSO_REDE.bat como administrador uma vez.
2. Execute INICIAR_SERVIDOR.bat.
3. O servidor mostra o endereco para os outros PCs.
4. Use ABRIR_SISTEMA.bat ou ABRIR_DASHBOARD.bat no PC principal.

OUTROS PCs:
Abra no Chrome/Edge o endereco HTTP mostrado pelo servidor, por exemplo:
http://192.168.1.20:3000

TESTE OBRIGATORIO:
http://IP_DO_SERVIDOR:3000/api/versao

Esperado:
{ "ok": true, "versao": "V20.0", ... }

IMPORTANTE:
- Nao execute uma copia antiga do server.js na porta 3000.
- Se a porta estiver ocupada, use REINICIAR_SERVIDOR.bat no PC servidor.
- O login, Dashboard, Avarias, Caixas, Tarefas, Perfil e Auditoria usam a mesma sessao do servidor.
- Abrir um HTML por duplo clique e suportado apenas como atalho de encaminhamento para o servidor; o sistema real sempre roda em HTTP.
