# Portfólio Wesley V5.0.4

Atualização da V5.0.3, mantendo as demais funções.

- Link externo de Controle de Avarias: https://andersonwesley09-alt.github.io/controle-de-avarias-web/
- Controle de Trocas continua sem URL externa (aplicação desktop), portanto o botão permanece informativo/desabilitado.
- Galeria de Controle de Trocas: principal, dashboard, histórico e administração, imagens selecionadas dos prints fornecidos.
- Ajustes visuais nos botões dos cards e na página de detalhes.

## Publicação manual

Na raiz do repositório GitHub, envie as versões de `projects.js`, `detail.js`, `style.css`, `data/projects.json`, `README_V5.4.md` e a pasta `assets` (com as quatro novas imagens WEBP). Não coloque os arquivos dentro da pasta de versão.

## Verificação

Após publicar no GitHub Pages, atualize com Ctrl+Shift+R e abra `projetos.html` e as páginas de detalhes. O botão Acessar projeto do Controle de Avarias deverá abrir a URL informada. O Controle de Trocas exibirá galeria com quatro imagens.
