V13.21 - TAREFAS DIÁRIAS / CHECKLIST

- Novo card Tarefas Diárias na tela inicial.
- Cada usuário possui seu próprio checklist por data.
- Usuário marca as tarefas concluídas.
- Administrador cria tarefas para um usuário específico ou para todos os usuários ativos.
- Administrador pode filtrar e excluir tarefas.
- Auditoria registra criação, conclusão, reabertura e exclusão.
- Tarefas incluídas no backup JSON automático.


V13.22 - Correção do carregamento de usuários no gerenciamento de tarefas. Criado endpoint dedicado /api/tarefas/usuarios e tratamento de erro no frontend.
