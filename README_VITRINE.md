# Controle de Avarias — Vitrine Web

Esta é a versão de demonstração do sistema.

- Frontend preservado da versão V25.1.20.
- Sem logo, fachada ou identidade da empresa original.
- Sem PostgreSQL, Node ou servidor central.
- As APIs são simuladas pelo `rede-central.js` dentro do navegador.
- Dados operacionais ficam somente na sessão do navegador.
- Login demo: `admin` / `admin123`.
