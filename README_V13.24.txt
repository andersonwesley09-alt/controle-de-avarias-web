CONTROLE DE AVARIAS - V13.24

Correção dos indicadores administrativos do módulo Tarefas Diárias:
- Para o administrador, os indicadores do topo agora usam exatamente as tarefas exibidas na tabela administrativa.
- Os números respeitam a data e o filtro de usuário selecionados.
- Quando um usuário conclui ou reabre uma tarefa, a tabela e os indicadores do administrador são atualizados pelo evento em tempo real.
- Usuários comuns continuam vendo os indicadores das próprias tarefas.
