# Projeto APP V16.3 - Controle de Avarias

## Atualização
- Adicionada ação "Ver senha" na gestão de usuários.
- Por segurança, a senha atual não é exibida: o banco armazena somente hash bcrypt.
- A janela de "Ver senha" orienta o administrador a usar "Redefinir senha" e oferece atalho para a redefinição.
- Adicionados botões de mostrar/ocultar senha nos campos de criação de usuário.
- Mantidas as funcionalidades da V16.2, incluindo categoria Bebidas e padronização de data/hora.
