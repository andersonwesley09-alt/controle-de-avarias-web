PROJETO APP V9 - FILTROS, ADMIN E TEMPO REAL

Base: V8 Azul e Logo.

Novidades:
1. Histórico com filtros por fornecedor, código do fornecedor, código do produto, data inicial e data final.
2. Somente usuários com perfil admin podem excluir registros do histórico. A regra é validada também no servidor.
3. Atualização em tempo real entre os PCs por Server-Sent Events (SSE), sem precisar atualizar a página manualmente.
4. Avarias, histórico, caixas, dashboard, usuários e resumo de produtos recebem atualizações automaticamente.
